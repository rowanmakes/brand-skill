# 路线

## 阶段 B0：原样测底座（现在）

不写任何规则。拿 brand-identity-skill 和 BrandDesign 原样跑两份简报（`test/briefs/`），回答：

1. 中文品牌名、中文字体能不能用？哪里坏了？
2. 用我们的模型（Gemini 4、OMP 加载的 GLM）跑，效果和它在 Claude Code 上的展示差多少？能跑完吗？
3. 三套方向你看了有没有一套"惊艳"？差在哪？
4. 两个底座哪个更好：一次出完整三套，还是先出黑白草图？

流程和提示词见 `docs/playbook.md`。

## 阶段 B1：按测试结果补（之后）

预计要补的，等 B0 结果确认：

- **策略层（放在最前面）：** 一句可验证的承诺、目标人群角色卡、三段语气示例、竞品清单。来自 Lovart；底座只问形容词和竞品。
- **情绪叙事：** 先用文字写出品牌的情绪，再谈视觉（来自 b1rdmania）。
- **中文：** 中文字标、中英混排，看 B0 坏在哪再补。字体不建库、不获取别人的字体文件（用户决定 2026-10-25）：只用底座能从 Google Fonts 合法取得的开源字体，或用户已有授权的字体。
- **物料：** 社媒、名片、包装样机（来自 BrandDesign），按需。
- **交给 UI Skill：** 品牌规范导出成 UI Skill 能直接用的 `DESIGN.md` 片段（北极星、色彩、字体、语气、不适合我们的设计）。

做法：底座是 MIT，可以 vendor 进来再改，保留许可和来源注释；或者只写我们的策略层，底座作为依赖安装。B0 之后决定。

## 不做

- 广告、邮件、投放这类营销内容。
- 编造 Pantone、CMYK、商标检索结论。
- 自建字体库、批量下载或转存别人的字体。
