# 中文字标做法（草案，B1-r1 测试用）

来源：B0 半山烘焙的失败点（`runs/b0-summary.md`）。还没测过，不进 Skill；B1-r1 跑完再按结果改。

## 为什么要这份

B0 六套方向里只有一套真正改了汉字，其余是现成字体排出来或转曲。评审的共同结论：没有专属中文字标，就到不了"惊艳"。

## 规则

1. **每套方向都要有一个画过的中文字标。** 字体转曲、只加一道切口都不算。在记录里写清楚改了哪几个字的哪几笔。
2. **四个字用同一套笔画语法。** 端点、切口角度、粗细关系、转角处理要一致。不能前两个字是自造几何、后两个字是现成宋体（乙A 的问题）。
3. **字义优先。** 改完先列出 3 种可能的误读（例："山"断成两排会被读成"出"或栅栏），有误读就改到没有为止。
4. **图标和字标共用一条规则。** 图标用了什么（斜切、切块、水平切层），字标上要看得到同一条规则，不是"图标 + 一款字体"。
5. **不靠解释成立。** 盖住说明文字，"半山"的意象还要读得出来。把品牌名换成另一家咖啡或茶店，如果照样成立，说明不够专属。
6. **小尺寸单独做。** 16px 下字义保不住时，另做一个小尺寸版本（比如只留首字或图标），写明在哪个尺寸切换；不要硬说"16px 清晰"。

## 技术注意（不改底座，在工作目录里绕开）

- 可变中文字体转曲后笔画是重叠的：先用 `pathops` 做并集，再做 evenodd 负空间。
- 中文高度按墨迹高度算，不按拉丁 cap-height（BrandDesign 会让图标偏小约 22%）。
- 中文说明按实际宽度换行，不按空格分词。
- 只用 Google Fonts 等合法来源的字体做起点。

## 展示与评审

- 并排展示，不加推荐标记，不加推荐边框。
- 评审用和设计不同的模型，并亲眼看 16/32/64px 实际渲染。
