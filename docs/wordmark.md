# 中文字标做法（草案 r2）

来源：B0 半山烘焙、B02 的失败点（`runs/b0-summary.md`）；r1 按 B1-r1 的 Codex 评审（`runs/b1-r1-banshan/review-codex.md`）改写。还没进 Skill。

## 为什么要这份

B0 两份简报十二套方向里，只有两套真正改了汉字，其余是现成字体排出来或转曲。评审的共同结论：没有专属中文字标，就到不了"惊艳"。B1-r1 证明这些规则能逼出真正的字标；也证明"画过"≠"惊艳"。

## 规则

1. **每套方向都要有一个画过的中文字标。** 转曲、描原字、统一加切口都不算。记录改造前后各一张同墨高对照，说明改了哪些骨架、比例或部件关系，以及为什么这样更好认。不以路径数证明独创。
2. **全词笔画成一家。** 端点、转角、粗细关系要成家族，不能前两个字是自造几何、后两个字是现成字体。允许为复杂字（如「烘焙」）减细、扩内白、改字宽，并记下这些光学例外；用整词的黑白密度和节奏检查，不要求每一笔同角度。
3. **字义优先，误读按证据记。** 先在不看说明的情况下记下实际读法，再列有证据的误读风险，不凑数量。独立评审检查偏旁、笔画连断、最小使用尺寸，逐项记录修前修后和剩余风险。不能宣称零误读；关键误读没解决，该尺寸就不通过。
4. **图标和字标共用一条主规则。** 提取一条最主要、看得见的规则，给出图和字对应的证据；不要求每个字机械复制全部细节（每字都切会伤结构）。和字义冲突时保字义并写明例外。纯字标路线不强制补图标。
5. **分开检查：读字、第一联想、专属性。** 盖住名称和说明，记录图形的第一联想；保持图形不变，实际并置至少两个同类名称，写清哪里仍成立、哪里不成立。"字标写着原名"不算专属证明。
6. **小尺寸单独做，区间要连续。** 按资产类型写连续的尺寸区间（不能漏 25–27px 这种空档），写明尺寸指外框还是墨高。至少实拍 16/24/32/64px 和切换点两侧。字义、图形、英文分别验收，英文要有自己的最小墨高（中英组合 48px 外框时英文只有约 5px，不够）。允许小版减少信息，但写明牺牲了什么。

## 技术注意（不改底座，在工作目录里绕开）

- 可变中文字体转曲后笔画是重叠的：先用 `pathops` 做并集，再做 evenodd 负空间。
- 中文高度按墨迹高度算，不按拉丁 cap-height（BrandDesign 会让中文偏大约 30%，图标相对偏小）。
- 中文说明按实际宽度换行，不按空格分词。
- 只用 Google Fonts 等合法来源的字体做起点。
- 成品 SVG 改过之后重新量尺寸，日志里的数字以成品为准。

## 展示与评审

- 并排展示，不加推荐标记，不加推荐边框。
- 评审用和设计不同的模型，并亲眼看 16/24/32/64px 实际渲染。
- 用户在 B0 喜欢的元素（如甲A 的红色中腰切块）转成黑白时，要说明它靠什么保住焦点；保不住就写明，不要默认等价。
