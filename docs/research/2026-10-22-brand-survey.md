# 品牌设计调研（2026-10-22）

## 一、Lovart 的品牌方法论

来源：[Lovart《AI 品牌设计完整指南》](https://www.lovart.ai/zh/blog/ai-branding-design)。只读了文章，没用过产品。

**五层：** 品牌承诺（一句可验证的话）→ 目标人群角色卡 → 视觉规范（三个形容词推色板、字体分工，最后做 Logo）→ 声音语调（三段"如果品牌是一个人"的示例）→ 触点规则（分渠道）。

**交付物：** 承诺、角色卡、色板、字体规范、Logo 及使用规范、触点规则、示例素材、品牌手册。

**可以借：**
- 先定规则再出图，Logo 是最后一步，不从 Logo 反推颜色。
- 承诺、人群、语气是决策层，归人；视觉规范和触点执行可交给 AI。
- 三秒辨识测试：Logo 和竞品并排，陌生人三秒内能否认出。
- 角色卡写到具体：日常、在哪买、信任谁、搜什么词。

**不借：**
- 形容词直接推颜色（温暖→暖色、天然→自然色、可信赖→深色）：这正是模型趋同的来源，和 UI 里"安静高级就是模型默认"同一个坑。
- "AI 生成 10 个 Logo 再挑"：没有要求和竞品拉开，也没有让 Logo、字体、颜色出自同一个想法。
- "一致性 93%"等数字：无来源，不作证据。

**判断：** 当骨架可用，是标准的品牌流程；照做出来是"标准答案"，不会惊艳。缺的是：方向之间要有真差别、并排让用户挑、和真实竞品对照、可测量的检查。

## 三、底座 brand-identity-skill 的要点

- **一个想法出整套：** 每套先写一句"机制"，由它同时决定 Logo、字体、颜色；只允许一个"大声"的部分（Logo 张扬则字体颜色安静，反之亦然）。
- **方向要真不同：** 每个品牌选 2–4 根轴（暖–冷、经典–当代、活泼–严肃、高端–亲民、安静–响亮、朋友–权威），三套至少在两根轴上分处两端；三套都在中间等于一个想法做三遍。
- **对照真实竞品**，写明每套和竞品差在哪。
- **AI 默认清单（偏置不是禁令）：** 实测 30 份简报 180 个回答：Fraunces 标题、Inter 正文、奶油底 + 陶土 + 金色、法律金融用藏青 + 金、科技用靛紫、Logo 公式"名字里的物件 + 藏字母 + 负形 + 圆 + 本地元素"。用到就要从简报里给具体理由，"感觉温暖/高级"不算；至少一套一个都不用。
- **品类套路：** 动手前先说出这个品类的三个套路（四角星、渐变球、圆角方块里的首字母、叶子、盾牌……）。
- **诚实：** 脚本量出的才叫"通过"，启发式标"警告"，审美标"判断"；不说某颜色"提升转化""建立信任"；不编 CMYK 和 Pantone。
- **测试数据：** 同 6 份简报，普通模型每个回答平均 4.38 个默认，24 个回答 0 个干净；用 skill 后每套 0.28 个，18 套中 13 套干净。跑到挑方向约 40 轮、约 86 万 token（Claude Code 上测）。
- **风险：** 文档里没有中文支持的说明（中文品牌名、中文字体、字形覆盖）；只在 Claude Code 端到端测过。

## 四、和 UI Skill 的共通点

两边独立得出了同样的结论：模型会滑向默认外观；要多方向并排、让用户挑；用"换个同类品牌还成立吗"检验；能量的交给脚本。UI Skill 的"换名字测试"和这里的"反射测试"是同一件事。
